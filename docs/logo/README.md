# The Coverussi logo

An album sleeve in five colour bands with a record sliding out, beside the name in Fraunces. `coverussi-light.svg` is the source; `scripts/logo.py` derives every other file here and the portal's copies from it. Change the source and run the script, not the others by hand.

| File | Use |
| --- | --- |
| `coverussi-light.svg` | The logo, for light backgrounds |
| `coverussi-dark.svg` | The logo, for dark backgrounds |
| `coverussi-mark.svg` | The sleeve and record alone, for favicons, app icons and anywhere square or small |
| `social.svg`, `social.png` | GitHub's social preview, 1280 × 640. Upload the PNG in the repo's Settings, General, Social preview |

| Thing | Value |
| --- | --- |
| Sleeve bands, top to bottom | `#421e89`, `#7e33aa`, `#e94f95`, `#5d2ca6`, `#7838a8` |
| Record label | `#5d2ca6` |
| Ink on light / on dark | `#16171B` / `#ECEEF1` |
| Accent | Pink `#e94f95`, with purple `#5d2ca6` as the second colour |
| Wordmark typeface | Fraunces, weight 600, optical size 144, SOFT 100, WONK 0 (SIL Open Font License). Title case "Coverussi" |

Rules:

- The wordmark is outlined to paths, so the files need no font.
- The dark logo only changes the record and the wordmark to `#ECEEF1`.
- In a square, centre the mark with padding. Don't stretch it.
